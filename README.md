# 3D Лабиринт с врагами (Ursina) — v1.1

Игра-шутер от первого лица на Python с использованием движка Ursina. 
Игрок перемещается по лабиринту из девяти комнат, сражается с двадцатью врагами-гуманоидами и финальным боссом.

## Что нового в v1.1
- **Враги-гуманоиды**: каждый враг состоит из головы, тела, рук и ног.
- **20 обычных врагов** (красные) с 1 HP, после уничтожения всех появляется **босс** (фиолетовый, в 2 раза крупнее, 5 HP).
- **Здоровье игрока**: 100 HP, отображается на экране. При контакте с врагом игрок получает урон (10 от обычного, 30 от босса) раз в секунду.
- **Условия победы и поражения**:
  - Убийство босса → сообщение «Игра пройдена!»
  - Здоровье упало до 0 → сообщение «Игра окончена»
- Исправлен вылет при спавне босса (`color.purple` заменён на `color.magenta`), добавлен `import time`.
- Пол теперь серый (текстура `ceiling.png` с серым оттенком).
- Убрана система бесконечных респаунов и счётчиков очков — теперь бой с фиксированным числом врагов.

## Возможности
- Лабиринт из 9 комнат (сетка 3×3) с дверными проёмами во все стороны.
- Окна на внешних стенах.
- Пользовательская текстура пола (`ceiling.png`).
- Составные модели врагов (голова, тело, конечности).
- Реалистичная стрельба с летящими пулями и эффектом взрыва.
- Ускоренный бег при удержании Shift.
- Индикатор здоровья и сообщения о конце игры.

## Управление
- `WASD` – движение
- `Мышь` – поворот
- `Левая кнопка мыши` – выстрел
- `Shift` – бег (скорость ×3)
- `Esc` – выход из игры
