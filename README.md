# My Shooter Game

Простая игра-шутер с двумя режимами: 2D и 3D. Написана на Python с использованием Pygame (для 2D и меню) и Ursina (для 3D).

## Версия 0.0.1

В этой версии:

- **3D-карта** увеличена в 10 раз: две комнаты размером **40×40 метров** каждая.
- **Дверной проём** между комнатами расширен до **2 метров** в ширину и **2.5 метров** в высоту (вровень со стенами).
- **Количество врагов** увеличено до **15** (красные шары), они появляются в обеих комнатах.
- Улучшена навигация и простор для манёвра.
- Оружие (пистолет) по-прежнему в руках, с анимацией отдачи.

## Возможности

- **Главное меню** – выбор режима, настройки, выход.
- **Настройки** – выбор цвета и формы персонажа для 2D-режима.
- **2D-режим** – вид сверху, стрельба по ботам, управление WASD + мышь.
- **3D-режим** – от первого лица, две большие комнаты, дверной проём, оружие в руках, враги (красные шары), счёт убийств.

## Требования

- Python 3.12 (или 3.11)
- Установленные библиотеки:
  - `pygame`
  - `ursina`

## Установка и запуск

1. Клонируйте репозиторий (или скачайте файлы).
2. Установите зависимости:
   ```bash
   pip install pygame ursina
(если используете несколько версий Python, укажите py -3.12 -m pip install pygame ursina)

Запустите игру через меню:

bash
python main.py
или сразу 3D-режим:

bash
python game_3d.py
Управление
В меню
Клик мышкой по кнопкам.

В 2D-режиме
WASD / стрелки – движение.

Левый клик мыши – выстрел в направлении курсора.

Здоровье отображается в левом верхнем углу.

В 3D-режиме
WASD – ходьба.

Мышь – осмотр (поворот камеры).

Левый клик – выстрел из пистолета.

ESC – выход из игры.

Структура проекта
main.py – главное меню и запуск режимов.

game_2d.py – 2D-игра (вид сверху).

game_3d.py – 3D-игра от первого лица с комнатами и оружием.

.gitignore – исключения для Git.

README.md – описание проекта.
