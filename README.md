# CUPER – 3D шутер с процедурной генерацией

Игра-шутер от первого лица, в которой игрок исследует лабиринт комнат, уничтожает врагов и сражается с боссом.

## Управление
- **WASD** – движение
- **Мышь** – осмотр
- **Shift** – бег
- **ЛКМ** – выстрел
- **Esc** – выход

## Установка и запуск
1. Установите Python 3.7+ и библиотеку Ursina: `pip install ursina`
2. Запустите игру: `python main.py` или дважды кликните `start_game.bat`

## Особенности
- Процедурно генерируемый лабиринт из 9 комнат
- Враги, которые преследуют и атакуют игрока
- Босс, появляющийся после уничтожения всех обычных врагов
- Текстуры и звук выстрела
- Анимированные враги (ходьба, прыжки)
