# My Shooter Game

**Шутер от первого лица с элементами исследования** – две игры в одной: классический 2D-режим и полноценный 3D-шутер с комнатами, окнами, врагами и оружием. Проект написан на Python с использованием библиотек Pygame (для меню и 2D) и Ursina (для 3D-сцены).

---

## Текущая версия: **v0.0.2**

В этой версии:

- **Три комнаты** (40×40 м каждая), соединённые дверными проёмами.
- **Окна** на внешних стенах с полупрозрачным стеклом и декоративными рамками.
- **Тёмный деревянный пол** и текстурированные стены (кирпич, плитка).
- **Точечное освещение** в каждой комнате – уютный тёплый свет.
- **20 врагов** (красные шары), которые преследуют игрока.
- **Оружие** (пистолет) с анимацией отдачи и видимой моделью.
- Свободное перемещение по всем комнатам, переходам и дверям.

---

## Возможности

- **Главное меню** – выбор режима (2D или 3D), настройки внешности персонажа для 2D, выход.
- **Настройки** – выбор цвета и формы (круг, квадрат, треугольник) для 2D-персонажа.
- **2D-режим** – вид сверху, стрельба по ботам, здоровье, управление WASD + мышь.
- **3D-режим** – полноценный шутер от первого лица с большими комнатами, дверями, окнами, оружием, врагами и счётом убийств.
- **Кроссплатформенность** – работает на Windows, Linux, macOS (при наличии Python и библиотек).

## Установка и запуск

1. **Клонируйте репозиторий** (или скачайте все файлы).
2. **Установите зависимости**:
   ```bash
   pip install pygame ursina
(если у вас несколько версий Python, используйте py -3.12 -m pip install pygame ursina)

Запустите игру через меню:

bash
python main.py
или сразу 3D-режим (без меню):

bash
python game_3d.py
Управление
В меню
Клик левой кнопкой мыши по кнопкам.

В 2D-режиме
WASD / стрелки – движение.

Левый клик мыши – выстрел в направлении курсора.

HP отображается в левом верхнем углу.

В 3D-режиме
WASD – ходьба вперёд/назад/влево/вправо.

Мышь – поворот камеры (осмотр).

Левый клик – выстрел из пистолета.

ESC – выход из игры.
